# 📝 NoteApp

A simple yet powerful **Sticky Notes Web App** built with **React**, **Recoil**, **Formik**, and **Axios**, allowing users to create, edit, and delete their personal notes securely.  
If you're not logged in, you can still view **public notes** but cannot add new ones until registration.

## 🌟 Features

- 🔐 **Authentication System** — Login & Register to create your notes.
- 🧾 **CRUD Operations** — Add, Edit, and Delete notes easily.
- 🌍 **Public Notes Page** — Non-logged-in users can view public notes.
- ⚡ **Responsive Design** — Works perfectly on mobile, tablet, and desktop.
- 🔁 **Real-time UI Update** — Instantly updates note count & content without refresh.
- 🌀 **Smart Loading States** — Beautiful spinners for fetching, adding, and updating data.
- 🎨 **Modern UI** — Built with Tailwind CSS & ShadCN components.

---

## 🛠️ Tech Stack

| Technology | Description |
|-------------|--------------|
| ⚛️ **React** | Frontend library for building user interfaces |
| 🎯 **Recoil** | State management for user data and note count |
| 🧠 **Formik** | Form handling and validation |
| 🌐 **Axios** | For API calls (GET, POST, PUT, DELETE) |
| 🎨 **Tailwind CSS** | Styling for fast and responsive UI |
| 🪄 **ShadCN/UI** | Modern prebuilt React UI components |
